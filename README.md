## Overview:

RATA [Remote Access Tool] is the RATA you'll ever need. This tool is an SSH [Secure SHell] RATA that is completely network-oriented, making it virtually fileless. It is capable of remotely connecting to the target computer, remote file uploads and downloads, as well as code execution **all** through network commands and communication.

Its advanced network capabilities make it difficult for standard antivirus and firewalls to detect. The RATA has a multitude of ways it can be installed onto a target PC, including batch file installation and the use of [Hak5](https://hak5.org) gear. Depending on how RATA is installed, you can have formatted as a _from GitHub_ or _from VPS_ install.

_From GitHub_ will install RATA from GitHub's raw data, allowing no user configuration. But the **connection can only be local** since there is no VPS to route traffic and forward ports from.

_From VPS_ will install RATA utilizing a Virtual Private Server (VPS) or any computer accessible on the internet to route traffic to and from the target. Meaning with this installer, you can **access your target from anywhere**.
